# PitchPack Agent Demo Video Script

Recommended length: 2 to 3 minutes.

## 1. Opening

Hi, this is PitchPack Agent, a creator and content operations agent built for the CROO Agent Hackathon.

Hackathon builders often have good technical projects, but weak final submissions. Their BUIDL descriptions are unclear, README files are incomplete, and demo videos are not structured. PitchPack Agent solves that problem.

## 2. Show the Input Form

Here I enter the project name, rough idea, target users, tech stack, and hackathon track.

Example idea:

> An AI wallet risk assistant that reads DeFi wallet activity and explains risky positions in simple language.

## 3. Generate Submission Pack

Now I click Generate Submission Pack.

PitchPack Agent converts the raw idea into a complete judge-ready submission pack.

## 4. Show the Outputs

The agent generated:

- DoraHacks BUIDL description
- Problem statement
- Solution summary
- Key features
- README starter
- 60-second pitch script
- Demo video script
- Social launch post

Each section can be copied and used directly during hackathon submission.

## 5. Show the CAP-Style Receipt

PitchPack Agent also generates a CAP-style job receipt. The receipt includes the task type, agent name, status, track, deliverables, timestamp, and proof metadata.

This demonstrates how PitchPack Agent can work as a callable service inside an agent economy, where a builder or another agent can hire it to perform content operations.

## 6. Closing

PitchPack Agent helps builders explain better, submit faster, and get discovered. It is simple, focused, and useful for the hackathon ecosystem.
